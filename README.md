# Samsung Sales Performance Analysis

A Microsoft Power BI project exploring Samsung sales performance through interactive dashboards and business-focused analysis.

## Project Overview

This report examines sales performance across product categories, customer segments, regions, and time periods. It is organized into five report pages, from an executive-level overview to more detailed performance views and a summary of insights.

## Tools

- **Microsoft Power BI Desktop** — report development and interactive data visualization

## Report Pages

1. **Executive Overview** — high-level sales performance metrics.
2. **Product Performance** — comparison of product categories.
3. **Customer Behaviour** — analysis of customer segments and behaviour.
4. **Sales Performance** — sales trends across regions and time.
5. **Executive Insights** — key takeaways presented in the report.

## Key Insights

The report's Executive Insights page identifies the following patterns:

- Smart TVs as the highest-revenue product category.
- Europe and Asia as strong-performing regions.
- Government customers as the highest-revenue customer segment.
- 5G-enabled devices contributing approximately 37% of total revenue.
- Discounts reducing gross revenue by approximately 5.7%.
- Month-to-month revenue fluctuations.

These are findings stated in the existing report and have not been independently recalculated against the underlying dataset as part of this repository documentation.

## How to View the Report

1. Download `Samsung Sales Performance.pbix` from this repository.
2. Open the file in Microsoft Power BI Desktop.
3. Explore the report pages and interact with the available visuals and filters.

Refreshing the report may require the original dataset or a configured data connection.
